# Herança em Java — Sistema de Animais

Projeto acadêmico desenvolvido do zero para praticar **herança e Programação Orientada a Objetos (POO)** em Java.

O exercício utiliza uma classe base chamada `Animal` e três subclasses: `Mamifero`, `Aves` e `Reptil`. Cada uma reúne características e comportamentos relacionados ao tipo de animal representado.

## Objetivo

Compreender como a herança permite reutilizar atributos e métodos de uma classe, adicionando características específicas nas subclasses.

## Tecnologia utilizada

- Java

## Conceitos praticados

- Classes e objetos;
- Herança com `extends`;
- Reutilização de atributos e métodos;
- Métodos getters e setters;
- Modificadores de acesso `public` e `private`;
- Sobrescrita do método `toString()` com `@Override`;
- Criação de objetos e execução de métodos na classe `Main`.

## Organização das classes

| Classe | Responsabilidade |
|---|---|
| `Animal` | Define características comuns: nome, tipo, idade, peso e sexo, além do método `dormir()`. |
| `Mamifero` | Herda de `Animal` e acrescenta pelos, amamentação, temperatura e o método `andar()`. |
| `Aves` | Herda de `Animal` e acrescenta bico, penas, capacidade de voo e envergadura das asas. |
| `Reptil` | Herda de `Animal` e acrescenta escamas, tamanho e o método `movimento()`. |
| `Main` | Cria os objetos, define suas características e exibe informações no console. |

## Aprendizado

Este exercício me ajudou a compreender a relação entre uma classe base e suas subclasses, diferenciando características comuns de características específicas.

Também pratiquei a criação de objetos, a utilização de métodos herdados e a sobrescrita de `toString()` para representar os dados de cada classe.
